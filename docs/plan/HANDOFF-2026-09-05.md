## How to run and see the app on this machine

The Mac mini is headless (no display) and this session is over SSH.
`screencapture` yields a black frame without a display; with a display it
works (Screen Recording is granted to `/usr/libexec/sshd-keygen-wrapper`).
Accessibility is not granted, so System Events keystrokes and clicks fail.

Use the in-app debug driver instead:

```
cd /Users/runner/workspace/neta
bun run build                                   # dist/main.js for the Node
apps/macos/scripts/build-app.sh /private/tmp/nfc/app   # bundle with the compiled neta
/private/tmp/nfc/drive/start-node.sh           # fresh NETA_DIR, temp git repo, Node, workspace.open
/private/tmp/nfc/drive/seed-missions.sh        # example seed (5 missions); restarts the Node
rm -rf ~/Library/Saved\ Application\ State/dev.neta.desktop.savedState
mkdir -p /private/tmp/nfc/drv1
NETA_DIR=/private/tmp/nfc/netadir NETA_DEBUG_DRIVER=/private/tmp/nfc/drv1 \
  /private/tmp/nfc/app/NetaDesktop.app/Contents/MacOS/NetaDesktop > /private/tmp/nfc/drv1/app.log 2>&1 &
printf 'resize 1600 1000\nwait 800\nshot /private/tmp/nfc/drv1/spine.png\n' > /private/tmp/nfc/drv1/cmd
cat /private/tmp/nfc/drv1/log                  # ok/error per command
/private/tmp/nfc/drive/stop-all.sh
```

Driver commands (see the header of `Shell/DebugDriver.swift`): `navigator
on|off`, `chat on|off`, `select leader|mission <n>|agent <name>`, `zoom
in|out`, `fit`, `now`, `resize w h`, `wait ms`, `shot <png>`, `state`,
`menu`, `key <spec>`, `click x y`, `window`, `quit` (and `draft <text>` once
the uncommitted change is finished). Each command file must end with a
newline; use one driver directory per app instance (two writers race).
`shot` draws the content view, so layout, text and colours are real but the
Liquid Glass blur does not render (surfaces look flat grey). Judging the
glass needs a display attached and a plain `screencapture`.

Other traps: `NETA_DIR` must be short (`/private/tmp/nfc` is a symlink to the
session scratch dir; socket paths over 104 bytes cannot bind); rebuilding the
bundle under a running instance kills it; `/private/tmp/nfc/drive/README.md`
documents the scripts (`rpc.mjs` for raw socket calls, `prompt2.mjs` to prompt
the leader with a tail subscription, `g4n-verify.mjs` for `tools.call`).
Worktrunk `wt` v0.72.0 is installed at `/Users/runner/.local/bin/wt`
(symlinked into Homebrew bin); the worktree test pins that version.
