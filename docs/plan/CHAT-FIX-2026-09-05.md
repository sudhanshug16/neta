## What changed

**Reset Chat.** Details now offers a destructive, confirmed Reset Chat action
for a workspace leader, mission lead, or ordinary agent. Reset starts a new
provider conversation with the same owner role, provider, model, access, Neta
tools, project, and mission instructions. It does not send the prior transcript
or a handoff. The old transcript remains stored. The durable owner is rebound
before the old provider is retired; candidate failure leaves the old owner and
chat usable, while cleanup failure after the commit cannot roll the new owner
back. Queued and archived agents cannot reset.

**Send while responding.** The composer keeps Send beside Stop during an active
response. Trusted native Claude and bundled Codex sessions use ACP steering;
custom providers and adapters without trusted steering support use a durable
FIFO inbox. Queued messages survive restart, deliver after the active turn,
and have explicit queued, delivering, delivered, uncertain, and discarded
states. Reconciliation after an uncontrolled service restart converts an
ambiguous interrupted delivery to `uncertain` instead of silently duplicating
it; controlled same-process provider recovery does not run that reconciliation.
Uncertain text is visible in a bounded list and has a native Copy message
action; retry remains a person's decision.

The default desktop Codex is the bundled Codex CLI 0.153.4 through the patched
Codex ACP 1.10 adapter. A configured provider `env.CODEX_PATH` remains
authoritative. Custom providers are deliberately not assumed safe for the ACP
steering extension.

**Long chats and following the live edge.** The transcript virtualizes at the
individual block level. A 500-block turn materializes fewer than 100 rows. The
cache bounds recent complete turns while keeping a single oversized active
turn intact, and older pages remain available.
Content revisions cover streaming block updates, tool updates, and terminal
metadata. Scroll following is based on actual geometry: streaming stays pinned
when the reader is at the bottom, reading older content is not interrupted,
and Jump to latest returns to the live edge. Reset clears a stale scroll anchor
when the session identity changes.
